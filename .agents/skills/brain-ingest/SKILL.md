# brain-ingest

Research basis: [[Obsidian Knowledge Structure]].

Read the actual source. Record its URL or local identity and unknown author/date honestly. Write a research note with type, status, author, reviewed, requirements and source_urls. Include a related wikilink. Save to brain/inbox and append brain/log.md. Run scripts/validate_docs.py. If the source is inaccessible, stop and record the gap. GitHub review is deferred for this local build.
