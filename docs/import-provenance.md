# Existing implementation import provenance

This is an import of a pre-existing, AI-assisted local Java MCP implementation into the owner's
repository, whose main branch already contained README.md and an MIT LICENSE. It is not a claim
that the upcoming 16-day team schedule produced the prior source history. Historical local notes,
tests and demos are retained with their dates and limits. No earlier peer reviews, CI runs or
team authorship are fabricated. New work requires real issues, PRs, checks and human review.

Origin main at bootstrap: a831da5355ff92832ef9f0991b26fad5343d4742.
The first import branch preserves that ancestry and the repository's existing MIT license.
The generated local LICENSE placeholder was superseded by the owner's repository license.
Dependencies retain their licenses. Client PDFs and their extracted text remain excluded by explicit owner instruction.

Scope: Java source/tests, Maven wrapper, PostgreSQL infrastructure, skills/evaluation scenarios,
PARA knowledge vault, documentation and quality scripts. Excluded: credential JSON, DPAPI vaults,
.local, .tools, target, release archives/staging, extracted client text and unapproved source PDFs.
The original external plan stays in the workspace; docs/team-plan.md is its portable snapshot.

Current evidence includes 3 November local verification and live tool-reported demos, with
remaining gaps documented in live-demo-status-2026-11-04.md. M1-S01 adds current baseline checks;
it does not automatically close historical acceptance gaps or replace all-stage skill evaluation.
