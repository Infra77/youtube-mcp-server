# ADR-0001: Java 21 and stdio

Status: accepted for local implementation, human review pending. Date: 2026-10-31.

## Context
See [[MCP Stdio Semantics]] and docs/SRS.md.

## Decision and alternatives
Use a single Maven module, Spring Boot 3.5 and compatible Spring AI 1.1. Pin published patch versions. Choose stdio over hosted HTTP to retain the local account trust boundary. Cost: users need a local Java process.

## Verification
Tests must exercise the described boundary, including negative and concurrent cases where relevant. Results are recorded in docs/test-results.md. GitHub issue/PR: DEFERRED.
