# ADR-0006: Exact proposal approval

Status: accepted for local implementation, human review pending. Date: 2026-10-31.

## Context
See [[Playlist Approval Invariants]] and docs/SRS.md.

## Decision and alternatives
Approval requires a real interactive console and review of complete immutable proposal. Bind digest, account and expiry. Commit accepts only draft ID. Atomic state claim prevents duplicate commits; remote ambiguous outcomes require review.
