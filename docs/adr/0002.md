# ADR-0002: Official provider boundary

Status: accepted for local implementation, human review pending. Date: 2026-10-31.

## Context
See [[YouTube Endpoint Matrix]] and docs/SRS.md.

## Decision and alternatives
Use an allowlisted official HTTP adapter behind YouTubeProvider and a separate fixture implementation. Reject scraping and arbitrary endpoint tools. Cost: metadata cannot establish spoken-content summaries.

## Verification
Tests must exercise the described boundary, including negative and concurrent cases where relevant. Results are recorded in docs/test-results.md. GitHub issue/PR: DEFERRED.
