# ADR-0003: PostgreSQL durability

Status: accepted for local implementation, human review pending. Date: 2026-10-31.

## Context
See [[Postgres Crash Recovery]] and docs/SRS.md.

## Decision and alternatives
Use PostgreSQL 16 with JDBC/Flyway for proposals, approvals, journals and quotas. Database row locks protect concurrent claims. In-memory/H2 state is not sufficient evidence of production crash/locking semantics.

## Verification
Tests must exercise the described boundary, including negative and concurrent cases where relevant. Results are recorded in docs/test-results.md. GitHub issue/PR: DEFERRED.
