# ADR-0005: Local PKCE and DPAPI

Status: accepted for local implementation, human review pending. Date: 2026-10-31.

## Context
See [[Google OAuth Desktop PKCE]] and docs/SRS.md.

## Decision and alternatives
Separate browser authorization CLI from MCP. Use state, S256 PKCE, ephemeral loopback, bounded callback lifetime and Windows DPAPI CurrentUser credential protection. Unsupported OS vaults fail closed. Request youtube.force-ssl for required read/write operations, not partner scope.

## Verification
Tests must exercise the described boundary, including negative and concurrent cases where relevant. Results are recorded in docs/test-results.md. GitHub issue/PR: DEFERRED.
