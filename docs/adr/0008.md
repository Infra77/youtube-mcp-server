# ADR-0008: Honest metadata semantics

Status: accepted for local implementation, human review pending. Date: 2026-10-31.

## Context
See [[Analytics Data Semantics]] and docs/SRS.md.

## Decision and alternatives
Overview uses metadata, not transcript. Trends use playlist/subscription added timestamps, never video publication for likes. Strict language matches declared defaultAudioLanguage, with explicit caveat that speech is not independently verified.
