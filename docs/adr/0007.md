# ADR-0007: Two-bucket bounded preflight

Status: accepted for local implementation, human review pending. Date: 2026-10-31.

## Context
See [[Quota Buckets and Reservation]] and docs/SRS.md.

## Decision and alternatives
Reserve all calls in a workflow before any provider request. Separate search and general budgets; Pacific quota dates; configurable costs. Consume budget before attempted calls and settle unused portions. Conservative abandoned reservations favor safety over automatic recovery.

## Verification
Tests must exercise the described boundary, including negative and concurrent cases where relevant. Results are recorded in docs/test-results.md. GitHub issue/PR: DEFERRED.
