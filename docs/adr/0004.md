# ADR-0004: Explainable ranking

Status: accepted for local implementation, human review pending. Date: 2026-10-31.

## Context
See [[TF-IDF and Cosine Similarity]] and docs/SRS.md.

## Decision and alternatives
Use smoothed corpus TF-IDF, cosine and weighted metadata features (0.55 text, 0.20 tags, 0.10 category, 0.10 duration, 0.05 language). Missing categorical evidence gives zero, stable ties use IDs. No model or vector database.

## Verification
Tests must exercise the described boundary, including negative and concurrent cases where relevant. Results are recorded in docs/test-results.md. GitHub issue/PR: DEFERRED.
